## 🚀 What I've Built in Production

<details>
<summary><b>🔷 GRIPP — Global Resilience Intelligence Platform &nbsp;(World Bank / Stanford)</b></summary>
<br/>

> Incremental ETL platform on Apache Airflow ingesting from **20+ heterogeneous global sources** — World Bank, IMF, GDELT, WTO, Meltwater, Conflict Forecast.

- ⚡ Parallelized DAG execution → **30% sync time reduction**
- 🔄 Normalized all inputs into a canonical schema for Data Scientists
- 🔬 Wired DS model pipeline runs directly into the Airflow DAG flow
- 📡 Full observability with **OpenTelemetry** — structured logging, monitoring, alerting

`Airflow` `Python` `Azure` `MinIO` `OpenTelemetry`

</details>

<details>
<summary><b>🔷 Xafe.ai — Privacy-Preserving ETL Engine &nbsp;(Sole Architect)</b></summary>
<br/>

> Middleware-controlled ETL platform processing **millions of rows** with runtime-configurable everything — zero code changes ever.

- 🧱 Parquet checkpoint staging → **40%+ memory reduction**, zero data loss on failure
- 🔐 Differential Privacy Engine — dynamic noise injection, PII masking, column-level encryption
- ⚙️ Runtime-configurable bulk/incremental modes, scheduling, source selection via Spring Boot
- 🛡️ Full **GDPR/CCPA** compliance — field encryption, access policies, configurable retention

`Airflow` `Python` `Spring Boot` `Parquet` `Differential Privacy`

</details>

<details>
<summary><b>🔷 Strategic Intelligence Platform &nbsp;(US Enterprise Client)</b></summary>
<br/>

> Polyglot ingestion pipeline handling REST APIs, XML, HTML, and PDFs with a Document AI layer for semantic search.

- 📥 Bulk + incremental ingestion across heterogeneous formats
- 💾 MinIO S3-compatible raw data lake
- 🧠 Document AI pipeline — **Docling + Qdrant** for semantic NL retrieval over unstructured docs

`Airflow` `Python` `Docling` `Qdrant` `RabbitMQ` `MinIO`

</details>

<details>
<summary><b>🔷 Namaiste.ai — Self-Hosted GenAI Platform</b></summary>
<br/>

> End-to-end RAG pipeline over **3,000+ documents** — entirely on-premise. No external LLM API calls.

- 🦙 **LLaMA 70B** on Ollama + LangChain + Qdrant vector store
- 📨 RabbitMQ-decoupled microservices for fault-tolerant parallel processing
- 🔒 On-premise LLM deployment ensuring complete data privacy
- 🔍 High-throughput document intelligence with semantic vector search

`LLaMA 70B` `Ollama` `LangChain` `Qdrant` `RabbitMQ`

</details>
